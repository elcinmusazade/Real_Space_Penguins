# Ares: First Light — shared guidebook

Read the root `AGENTS.md` and `README.md`, then:

| File | Purpose |
| --- | --- |
| `PROJECT.md` | Product goals, confirmed user choices, and implementation defaults |
| `STATUS.md` | Verified current state and remaining work |
| `ARCHITECTURE.md` | Source ownership, modules, and run/test instructions |
| `DECISIONS.md` | Important decisions and their reasoning |
| `DATA_SOURCES.md` | Scientific references and limitations |
| `IDEAS.md` | Future ideas that are **not** implemented commitments |
| `PROMPTS.md` | Reusable prompts for a new chat |
| `changes/` | One uniquely named history entry per meaningful task |

Code is the authority for what exists. Inspect it before updating this guidebook. Record new implementation and its observed checks together; do not confuse a proposed feature with a working one.
